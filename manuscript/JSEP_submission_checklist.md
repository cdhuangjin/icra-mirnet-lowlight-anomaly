# JSEP Submission Checklist

- [x] Editable LaTeX manuscript source exists.
- [x] Matching peer-review PDF exists.
- [x] Abstract is within the stated 200-word limit and contains no citations.
- [x] Five keywords are present.
- [x] Main results are traceable to frozen experimental artifacts.
- [ ] Author/title page completed from verified metadata.
- [ ] Short title is confirmed at 70 characters or fewer.
- [ ] ORCID and corresponding-author details entered.
- [ ] Data and code availability statements approved.
- [ ] Funding, competing-interest, ethics, consent, and permissions statements approved.
- [ ] Tables moved to separate pages if requested by the editorial workflow.
- [ ] Figures prepared as separate high-resolution files.
- [ ] GTOC figure and 80-word maximum text prepared.
- [ ] PDF rebuilt after all metadata and format edits.
- [ ] Submission files checked for readable text, figures, tables, and references.
